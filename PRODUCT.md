# PubMed Research Intelligence
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User-confirmed React, Vite, TypeScript, Tailwind, ECharts, Python FastAPI, httpx and local JSON cache.

## Users
An interview candidate demonstrating biomedical research intelligence to evaluators.

## Product Purpose
Turn a biomedical query into a truthful, inspectable research landscape, paper ranking, and Chinese research brief.

## Operating Context
One-day demo scope. Local frontend and backend; no database. Real PubMed metadata; an Alzheimer's snapshot enables offline demonstrations.

## Capabilities and Constraints
The interface supports English and Simplified Chinese through an immediate navigation toggle, with browser-local persistence. Switching preserves active queries, analysis data, paper sorting and expansion. Original publication metadata remains in its source language; the brief remains Chinese as required.
Download 300–1000 recent articles (default 500). Distinguish full-query counts from sample analytics. Explain journal metrics, sampling limitations and AI fallback. Never invent papers, metrics or provenance. API keys remain on the backend. The user approved the implementation plan on 2026-10-13.

## Brand Commitments
White/light gray, primary #2563EB, secondary #06B6D4, text #0F172A; professional scientific dashboard with restrained movement and maximum width 1400px.

## Evidence on Hand
No dataset at scaffold time. A real NCBI snapshot must be fetched and verified before claiming offline readiness.
